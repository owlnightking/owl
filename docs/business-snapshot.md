# BUSINESS SNAPSHOT — Owl 业务功能现状与最新计划

## 一、业务领域地图

| 领域       | 定位                                                                 | 主要入口               | 开发顺序         |
| ---------- | -------------------------------------------------------------------- | ---------------------- | ---------------- |
| 主领域     | 自研产品跨境电商业务系统（13 阶段流水线 / 利润聚合，owl-web 工作台） | owl-web + admin-web    | 后做（远期保留） |
| 组织支撑域 | 认可中心、人才中心、智能客服 + 内部知识库、基础配置与监控、协同底座  | admin-web + mobile-web | 先做（当前）     |
| 副业域     | 付费知识（md 组件创作的文档库，文本入库持久化，商业化后置）          | mobile-web + admin-web | 次做             |

全局口径：触点按角色不按端；RBAC 按钮级四层（菜单可见 / 页面可进 / 按钮可点 / 接口校验）；初期仅超管 / 普通员工两角色；登录本地 mock 可切角色、生产真飞书；内站消息先轮询后升级。

## 二、功能现状（按域）

| 功能                 | 规则要点                                                                     | 角色                | 入口           | 状态            |
| -------------------- | ---------------------------------------------------------------------------- | ------------------- | -------------- | --------------- |
| 认可贴发布/审批/置顶 | 员工发起（被认可人+徽章+留言）→ 待审批推送超管 → 通过进全员 Feed；超管可置顶 | 全员发起 / 超管审批 | mobile + admin | 规划            |
| 徽章管理             | 徽章 CRUD；徽章图走文件服务                                                  | 超管                | admin          | 规划            |
| 产币 / 等级          | 仅认可贴审批通过产币：被认可人获固定币（可配）+ 经验；点赞不产币             | 系统                | -              | 规划            |
| 体力 / 防刷          | 点赞耗体力（月重置、上限可配）；同人对同贴限赞 1 次                          | 全员                | mobile         | 规划            |
| 兑换审核             | 下单即时扣币 → 超管审核：通过=发货/领取核销并减库存；驳回=退币               | 全员兑换 / 超管审   | mobile + admin | 规划            |
| 商城商品上架         | 商品（名称/图/价格/库存/上下架）                                             | 超管                | admin          | 规划            |
| 我的（员工侧）       | 币余额 / 等级经验 / 体力月重置 / 发起认可 / 兑换记录                         | 全员                | mobile         | 规划（现 mock） |

## 三、最新计划与排期

- 当前里程碑 M2'：S0 支撑域底座 → S1 认可中心闭环（admin + mobile），需求基线已确认，开发未开始
- 后续顺序：S2 人才中心 → S3 智能客服 + 知识库 → S4 基础配置与监控 → B1 付费知识（副业）→ M0 主领域流水线
- 排期与验收细节见 `docs/implementation-plan.md`；定位决策见 `docs/decisions/002-product-positioning-and-roadmap.md`
