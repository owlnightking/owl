## 维护规则

1. 新增 ADR：在 `docs/decisions/` 建 `NNN-<slug>.md`，同步在本表加一行。
2. 决策被取代：不改原文，新开更高编号 ADR，并在本表把旧条目状态改为「部分取代 / 已废弃」。
3. 文档整份废弃：移动到 `docs/archive/`，顶部写明「已废弃 + 取代它的文档」，并更新本表与所有引用。
4. 校验：`pnpm doc:links` 会检查 `docs/`、根级文档与 `scripts/` 的本地引用是否存在。
